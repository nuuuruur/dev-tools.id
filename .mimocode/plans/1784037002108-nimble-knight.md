# Plan: Add Shell Alias for Generator

## Goal
Add a shell alias so `python3 generate.py` can be run with a shorter command.

## Approach

Add an alias to `~/.bashrc`:

```bash
alias gen="python3 /workspaces/dev_tools/generate.py"
```

## File to Modify

- **`~/.bashrc`** — Append the alias

## Verification

1. Run `source ~/.bashrc`
2. Run `gen` from any directory — should generate README.md successfully
